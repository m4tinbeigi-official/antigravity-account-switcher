⚡️ سوئیچ آنی زیر ۳ ثانیه

جابه‌جایی سریع بین اکانت‌های گوگل
در Google Antigravity

ابزار کاملاً نیتیو، امن و خودکار برای جابه‌جایی سریع و بی‌دردسر بین اکانت‌های کاری و شخصی در مک (Apple Silicon & Intel) و ویندوز.

نصب خودکار با یک دستور (Terminal):

git clone https://github.com/m4tinbeigi-official/antigravity-account-switcher.git && cd antigravity-account-switcher && ./install.sh

✓ اپلیکیشن AntigravitySwitcher.app روی دسکتاپ و در مسیر Applications نصب شده و از Spotlight (زدن Cmd+Space) یا دستور ترمینال agy-switch قابل اجراست.

نصب و اجرای آسان در ویندوز (PowerShell):

git clone https://github.com/m4tinbeigi-official/antigravity-account-switcher.git; cd antigravity-account-switcher; .\install.bat

✓ سازگار با ویندوز 10 و 11. با اتصال مستقیم به Windows Credential Manager بدون نیاز به پکیج‌های اضافی.

⚡️

سوئیچ با یک کلیک

نیازی به ورود مجدد به مرورگر یا تایپ نام‌کاربری و رمز نیست. توکن‌های امن جابه‌جا شده و برنامه آنی با اکانت جدید بالا می‌آید.

🔒

امنیت ۱۰۰٪ آفلاین

هیچ اطلاعاتی به سرورهای خارجی ارسال نمی‌شود. تمام داده‌ها در macOS Keychain و Windows Credential Manager محلی نگهداری می‌شوند.

🚀

پشتیبانی دوال نیتیو

نسخه مک به صورت Universal 2 (پشتیبانی همزمان از چیپ‌های M1/M2/M3/M4 و اینتل) و نسخه ویندوز به صورت نیتیو اجرا می‌شوند.
