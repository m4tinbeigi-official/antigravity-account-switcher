سوئیچ آنی بین اکانت‌های گوگل
در Google Antigravity

ابزار کاملاً نیتیو، امن و خودکار برای جابه‌جایی سریع و بی‌دردسر بین اکانت‌های کاری و شخصی در مک (Apple Silicon & Intel) و ویندوز.

نصب خودکار در مک با یک دستور:

git clone https://github.com/m4tinbeigi-official/antigravity-account-switcher.git && cd antigravity-account-switcher && ./install.sh

✓ اپلیکیشن AntigravitySwitcher.app روی دسکتاپ و در Applications نصب شده و از طریق Spotlight (زدن Cmd+Space) یا دستور ترمینال agy-switch قابل استفاده است.

نصب و اجرای آسان در ویندوز:

git clone https://github.com/m4tinbeigi-official/antigravity-account-switcher.git; cd antigravity-account-switcher; .\install.bat

✓ سازگار با ویندوز ۱۰ و ۱۱. اتصال مستقیم به Windows Credential Manager بدون نیاز به پکیج‌های اضافی.

⚡️

سوئیچ با یک کلیک

نیازی به ورود مجدد به مرورگر نیست. توکن‌های امن جابه‌جا شده و برنامه در کسری از ثانیه با اکانت جدید باز می‌شود.

🔒

امنیت ۱۰۰٪ آفلاین

اطلاعات هرگز به سروری ارسال نمی‌شوند. توکن‌ها مستقیماً داخل macOS Keychain و Windows Credential Manager سیستم خودتان نگهداری می‌شوند.

🚀

پشتیبانی دوال نیتیو

نسخه مک به صورت Universal 2 (پشتیبانی همزمان چیپ‌های سری M اپل و پردازنده‌های اینتل) و نسخه ویندوز به صورت نیتیو اجرا می‌شوند.
